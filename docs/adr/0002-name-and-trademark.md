# 0002 — Project name `relic-bridge` and trademark posture

- Status: accepted
- Date: 2026-10-01

## Decision
- Name: **relic-bridge**. npm: the unscoped `relic-bridge` (CLI) and the `@relic-bridge/*` scope for libraries were both
  unclaimed on 2026-10-01 (P0-01); the maintainer reserves them before the first release.
- The README, docs and package descriptions state clearly: *"relic-bridge is an unofficial, community project. It is not
  affiliated with, endorsed by, or supported by New Relic, Inc. New Relic and NerdGraph are trademarks of New Relic, Inc."*
- No New Relic logos or brand colours in the admin UI or docs.

## Consequences
- Lower trademark risk; the name still tells users what the tool does.
