# P4-11 — Admin panel in a real browser: Playwright E2E and guide screenshots

## Goal
P4-04 drives the admin screens over HTTP (the panel needs no JavaScript). A real browser additionally proves what HTTP
tests cannot: the CSP and Trusted Types do not break the page, the copy button works, the layout holds at 320 px, and
it gives the admin guide its screenshots.

## Scope
- `@playwright/test` (Chromium only) as a dev dependency with a `pnpm test:e2e` script, outside `pnpm test`.
- A spec that starts `relic-bridge serve` on a temporary SQLite database with a mock IdP and a NerdGraph stand-in
  (no real keys), signs in through a setup link and repeats the P4-04 personal setup (2 credentials US/EU,
  2 projects, 3 device tokens) by clicking, at desktop and 320 px widths; fails on any CSP violation or console error.
- Screenshots for `docs/guide/admin-panel.md`, regenerated by a script (light and dark).
- A CI job (pinned actions, cached browser download) or a documented manual run: owner's choice (CI minutes).

## Acceptance criteria
- [ ] The spec passes locally and in the chosen CI setup; no CSP violation reports.
- [ ] The admin guide shows current screenshots.

## Security notes
Test keys and tokens only; screenshots must not show a real key, token or email.

## Docs to update
- `docs/guide/admin-panel.md`, `CONTRIBUTING.md` (how to run the browser tests).

## Out of scope
- Cross-browser runs beyond Chromium.
